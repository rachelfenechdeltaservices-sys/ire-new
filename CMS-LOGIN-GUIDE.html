How to set up your CMS login

Five steps to sign in at top10irishcasino.site/admin with your own username and password, and one optional step so your changes go live automatically. Takes about 20 minutes.

At a glance: what you need to update

Everything for the login lives in one private file, cms-config.php. It's in the download at cms-private/cms-config.php, already filled in with your repository and branch. You only need to change two things:

Setting in cms-config.phpWhat to put there
'token'Your GitHub access token (step 2). It starts with github_pat_Update
'users'One line per person who can sign in (step 4)Update

Then upload that file to your hosting in a folder next to public_html, not inside it (step 5).

1

Upload the website

Hosting control panel

Open the download top10irishcasino-website.zip. It has two folders that mirror your hosting account:

top10irishcasino-website.zip
├── public_html/        ← the website: upload everything inside it to your public_html
│   ├── index.html, casino.html, … (all pages)
│   ├── .htaccess       ← short links /link1 … and security settings
│   ├── admin/          ← the CMS
│   └── assets/
├── cms-private/
│   └── cms-config.php  ← the private settings file (steps 3–5)
└── CMS-LOGIN-GUIDE.html
  1. In your hosting control panel (e.g. cPanel) open File Manager → public_html.
  2. Upload the contents of the zip's public_html folder there. The easiest way is to upload the zip, Extract it, then move the files out of the extracted public_html folder.
  3. Make sure hidden files such as .htaccess were uploaded. In cPanel: Settings → Show Hidden Files.
Check it worked: top10irishcasino.site shows the new website and /admin/ shows the CMS start screen. Signing in won't work yet.
2

Create a GitHub access token

github.com

This lets the CMS save your edits to the GitHub repository. Sign in to GitHub as the account that owns rachelfenechdeltaservices-sys/ire-new, then:

  1. Click your profile picture (top right) → Settings.
  2. At the bottom of the left menu: Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: Top 10 Irish Casino CMS
  4. Expiration: choose up to 1 year, and put a reminder in your calendar to renew it.
  5. Repository access: Only select repositories → choose ire-new.
  6. Permissions → Repository permissions → Contents: set to Read and write. (Metadata: Read-only is added automatically. Nothing else is needed.)
  7. Click Generate token and copy it straight away. GitHub only shows it once.
Keep the token secret. Anyone with it can change the website's content. Don't email it or paste it into chats; it only goes into cms-config.php.
3

Put the token in cms-config.php

Text editor

Open cms-private/cms-config.php from the download in a plain text editor (Notepad, TextEdit in plain-text mode, or the cPanel File Manager editor). Replace the highlighted placeholder with your token:

'github' => [
    'repo'   => 'rachelfenechdeltaservices-sys/ire-new',
    'branch' => 'adding-cms',
    'token'  => 'github_pat_PASTE_YOUR_TOKEN_HERE',   ← paste your token between the quotes
],

Example once filled in: 'token' => 'github_pat_11ABCDEF…',. Keep the quotes and the comma at the end.

4

Create your username and password

Your website
  1. Go to top10irishcasino.site/admin/make-password.php.
  2. Type the username and password you want to sign in with (at least 12 characters), then click Create login line.
  3. It shows a line like this. Copy it: 
    'rachel' => '$2y$10$Jx3k…long scrambled text…',
  4. Paste it inside the 'users' => [ … ] list in cms-config.php: 
    'users' => [
    'rachel' => '$2y$10$Jx3k…long scrambled text…',   ← your pasted line
],
Your password is never stored; only this one-way scrambled version is. To add more people, repeat this step and paste one line per person. To remove someone, delete their line.
5

Upload cms-config.php to your hosting

Hosting File Manager

The file must go in a folder called cms-private next to public_html, not inside it, so it can never be opened from the web:

/home/your-account/
├── cms-private/
│   └── cms-config.php     ← upload it here
└── public_html/           ← the website (step 1)
    ├── index.html
    └── admin/
  1. In File Manager go to your home folder (one level above public_html).
  2. Click + Folder and create cms-private.
  3. Open it and Upload your edited cms-config.php.
Already put it in public_html? That works too: the CMS also finds public_html/cms-config.php (or public_html/admin/cms-config.php). The website's .htaccess blocks anyone from opening or downloading it there; make sure that .htaccess is the new one from the download.
6

Sign in

Your website
  1. Open top10irishcasino.site/admin/.
  2. Click Sign In with Username & Password. A small window opens.
  3. Enter the username and password from step 4 → Sign in. The window closes and the CMS opens.

You'll see Offers, Reviews, Pages, FAQ and Site settings. To change the order of offers, open Offers → Sportsbook offers and drag them (or use Move Up / Move Down), then click Save.

Allow pop-ups for top10irishcasino.site if the sign-in window doesn't appear. On a shared computer, use Sign Out (account menu, top right) when you're done.
7

Optional: make saves go live automatically

github.com

When you click Save, your change is stored on GitHub. Add your FTP details once, and GitHub will rebuild the pages and upload them to your hosting after every save (live in about 1–2 minutes):

  1. On GitHub open the ire-new repository → Settings → Secrets and variables → Actions → New repository secret. Add these three (from your hosting panel's FTP Accounts):
    NameValue
    FTP_SERVERe.g. ftp.top10irishcasino.site
    FTP_USERNAMEyour FTP username
    FTP_PASSWORDyour FTP password
  2. Still in Settings: Actions → General → Workflow permissions → choose Read and write permissions → Save.
  3. If your host doesn't support secure FTP (FTPS): on the Variables tab add FTP_PROTOCOL = ftp.

Without this step you can still sign in and save. You'd then re-upload the website by hand to publish changes.

Checklist

  • Website uploaded to public_html, including .htaccess
  • GitHub token created (Contents: Read and write, repository ire-new only)
  • Token pasted into cms-config.php
  • Your login line pasted into the 'users' list
  • cms-config.php uploaded to cms-private/, next to public_html
  • Signed in at /admin/
  • (Optional) FTP secrets added on GitHub for automatic publishing

If something doesn't work

You see…Fix
An error box straight away on /admin/cms-config.php wasn't found. Check its name and that it's in cms-private/ next to public_html, or directly in public_html (step 5).
"The GitHub access token … has not been filled in yet"Paste your token into 'token' (step 3) and upload the file again.
"No CMS users are set up"Paste your login line into 'users' (step 4).
"Incorrect username or password"Usernames ignore capital letters; passwords don't. Create a new line at make-password.php if unsure.
"Too many failed attempts"Wait 15 minutes (if cms-config.php is in cms-private, you can also delete .cms-login-attempts.json there).
Signed in, then an error about access or "Bad credentials"The token is wrong, expired, or doesn't have Contents: Read and write on ire-new. Make a new one (step 2).
Saved, but the website didn't changeOn GitHub open Actions and look at the latest Build & deploy website run. Step 7 may be missing.
The sign-in window doesn't openAllow pop-ups for the site in your browser.
